# Learning

## Overview
Raw notes decay. Durable knowledge requires **encoding** (Feynman) and **retrieval** (spaced repetition). This skill converts any input — lecture, article, codebase — into a small set of high-yield artifacts.

## When to Use
- After reading/watching/learning something new
- When reviewing existing notes before an interview
- When you keep forgetting the same thing

## Process

### Step 1: Feynman (5 min)
- Explain the concept in plain language to a 12-year-old
- Where you stumble = gaps in understanding
- Fill gaps, then re-explain until smooth

### Step 2: Extract the 3 things
Every topic yields at most 3 high-value items:
- **One core idea** (the "why")
- **One mechanism** (the "how")
- **One trade-off** (the "when not to")

Write each in one sentence. If you can't, you don't understand it yet.

### Step 3: Create retrieval cards
Format: `Q: <question> → A: <answer in ≤2 lines>`

Rules:
- One concept per card
- Answer ≤ 2 lines (forces compression)
- Include a "why" or "when" on at least half

### Step 4: Spaced repetition schedule
- Day 0: create cards
- Day 1: review (5 min)
- Day 3: review (3 min)
- Day 7: review (2 min)
- Day 14: review (1 min)
- Day 30: final review, archive or promote

### Step 5: Connect to existing knowledge
- "This is like X, except Y"
- Link to one existing note/concept
- If no link exists, the concept is isolated — re-examine

## Red Flags
- Notes longer than 1 page per topic (you're transcribing, not learning)
- No retrieval practice (re-reading ≠ learning)
- Cards with answers > 2 lines
- Skipping the Feynman step ("I already understand it")
- Hoarding notes without reviewing

## Rationalizations

| Excuse | Reality |
|---|---|
| "I'll review later" | You won't. Schedule it now. |
| "More notes = more learning" | Compression is the learning. |
| "I understand it, no need to explain" | Feynman exposes gaps. Always. |
| "Spaced repetition is too much overhead" | 15 min/week beats 5 hours cramming. |

## Verification
- [ ] Feynman explanation written (plain language)
- [ ] 3 core items extracted (idea/mechanism/trade-off)
- [ ] Retrieval cards created (≤2 lines each)
- [ ] Review schedule set
- [ ] Connected to at least one existing concept
- [ ] Can explain it without notes
