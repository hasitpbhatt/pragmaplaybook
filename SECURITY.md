# Security Policy

## Supported versions

Only the latest release on main is supported with security fixes.

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities.

Report security concerns by email to hasit.p.bhatt@gmail.com with a description of the issue and impact, steps to reproduce, and any suggested fix. You will receive an acknowledgment within 7 days.

## Scope

This repository contains Markdown skills only (no executable code, no network access, no secrets).
