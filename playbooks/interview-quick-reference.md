# Interview Quick Reference

## DSA loop
Clarify → Brute force → Optimize → Code → Test → Discuss

## Complexity targets
- O(n) or O(n log n) for n ≤ 10⁶
- O(n²) only for n ≤ 10³

## Behavioral (STAR)
- Situation (2 sentences) → Task → Action (use "I") → Result (quantified + learned)

## Honesty gates
- "I don't know" beats confident wrong
- Admit failures, show what changed
- Don't claim team wins as personal
