# AGENTS.md

This repository contains agent skills for interviews, PR reviews, learning, incident response, debugging, TDD, planning, and retrospectives.
When reviewing a PR, load `skills/pr-review/SKILL.md`.
When preparing for a system design interview, load `skills/system-design/SKILL.md` (plus its companion `skills/system-design/canvas.md`).
When preparing for a coding/behavioral interview, load `skills/coding-interview/SKILL.md`.
When turning notes into durable knowledge, load `skills/learning/SKILL.md`.
When responding to a production incident, load `skills/incident-response/SKILL.md`.
When planning multi-session work, load `skills/wayfinder/SKILL.md`.
When building a feature test-first, load `skills/tdd/SKILL.md`.
When debugging a hard bug, load `skills/debug/SKILL.md`.
When stress-testing a plan or design, load `skills/grill/SKILL.md`.
After a coding session, run a retro with `skills/retro/SKILL.md`.

## Rules

- Every skill must be concise. If a SKILL.md exceeds ~200 lines, split it.
- Every skill must include these six sections in this order: Overview, When to Use, Process, Rationalizations, Red Flags, Verification.
- No skill may be merged without a verification section.
- Prefer deletion over addition. A skill that removes complexity beats one that adds it.
