# Definition of Done

Every change clears this bar:

- [ ] Matches spec/task requirements
- [ ] Edge cases handled
- [ ] Error paths handled
- [ ] Tests pass (behavior, not implementation)
- [ ] Build succeeds
- [ ] No secrets in code
- [ ] Input validated at boundaries
- [ ] No N+1 / unbounded ops
- [ ] Change ≤ ~300 lines (or justified)
- [ ] Verification story documented
- [ ] Verdict: Approve or Request changes
